## What This Chapter Is

Loops allow code to execute repeatedly without manual duplication. This chapter covers `for`, `while`, and `do-while` loops, along with classic problems like FizzBuzz.

### FizzBuzz.js
The classic interview problem:
- Loop from 0 to 99
- Divisible by 3 (not 5): print "Fizz"
- Divisible by 5 (not 3): print "Buzz"
- Divisible by both: print "FizzBuzz"
- Otherwise: print the number

### Trianagle_Clasiifier.js
Given three side lengths, classify the triangle:
- All sides equal = Equilateral
- Two sides equal = Isosceles
- No sides equal = Scalene
- Invalid input = Not a triangle

## Why This Matters

Repetition is everywhere in programming and testing. Loops allow concise, maintainable code that operates on collections, processes data, and performs repeated checks.

FizzBuzz specifically tests the ability to combine loops, conditionals, and the modulus operator — a common interview benchmark.

---

## What You'll Learn

- `for` loop: count-controlled iteration
- `while` loop: condition-controlled iteration
- `do-while` loop: execute at least once
- FizzBuzz problem-solving pattern
- Nested conditions within loops
- Loop interview patterns

---

## Key Terms

| Term | Definition |
|---|---|
| Loop | Repeated execution of a code block |
| For | "Start here, continue while true, step each time" |
| While | "Keep going as long as condition is true" |
| Do While | "Execute once, then check condition" |
| Iterate | One pass through a loop body |
| FizzBuzz | A common programming interview problem |

# VS Code Keyboard Shortcuts for Mac

## General
| Action | Shortcut |
|--------|----------|
| Command Palette | `Cmd + Shift + P` |
| Quick Open | `Cmd + P` |
| Settings | `Cmd + ,` |
| Keyboard Shortcuts | `Cmd + K Cmd + S` |

## Editing
| Action | Shortcut |
|--------|----------|
| Cut line | `Cmd + X` |
| Copy line | `Cmd + C` |
| Paste | `Cmd + V` |
| Move line up/down | `Alt + ↑ / ↓` |
| Copy line up/down | `Shift + Alt + ↑ / ↓` |
| Delete line | `Cmd + Shift + K` |
| Insert line below | `Cmd + Enter` |
| Insert line above | `Cmd + Shift + Enter` |
| Indent / Outdent | `Cmd + ] / [` |
| Go to beginning of line | `Cmd + ←` |
| Go to end of line | `Cmd + →` |
| Comment line | `Cmd + /` |
| Block comment | `Shift + Alt + A` |
| Find | `Cmd + F` |
| Replace | `Cmd + Option + F` |
| Find next / previous | `Cmd + G / Cmd + Shift + G` |

## Multi-Cursor & Selection
| Action | Shortcut |
|--------|----------|
| Select all occurrences | `Cmd + Shift + L` |
| Add cursor above/below | `Cmd + Option + ↑ / ↓` |
| Undo last cursor | `Cmd + U` |
| Column selection | `Shift + Option + drag` |
| Expand selection | `Ctrl + Shift + Cmd + →` |

## Navigation
| Action | Shortcut |
|--------|----------|
| Go to file | `Cmd + P` |
| Go to symbol | `Cmd + Shift + O` |
| Go to line | `Ctrl + G` |
| Go back / forward | `Ctrl + - / Ctrl + Shift + -` |
| Toggle sidebar | `Cmd + B` |
| Toggle terminal | `Ctrl + \`` |
| Open file in new tab | `Cmd + Enter` (from Quick Open) |

## Search & Replace
| Action | Shortcut |
|--------|----------|
| Search in files | `Cmd + Shift + F` |
| Replace in files | `Cmd + Shift + H` |
| Toggle search details | `Cmd + Shift + J` |

## Debug
| Action | Shortcut |
|--------|----------|
| Start / Continue | `F5` |
| Step over | `F10` |
| Step into | `F11` |
| Step out | `Shift + F11` |
| Toggle breakpoint | `F9` |
| Stop | `Shift + F5` |

## Terminal
| Action | Shortcut |
|--------|----------|
| Toggle terminal | `Ctrl + \`` |
| New terminal | `Ctrl + Shift + \`` |
| Clear terminal | `Cmd + K` |

## Split Editor
| Action | Shortcut |
|--------|----------|
| Split editor | `Cmd + \` |
| Switch between editors | `Cmd + 1 / 2 / 3` |
| Close editor | `Cmd + W` |
| Close all editors | `Cmd + K W` |

## Code Editing
| Action | Shortcut |
|--------|----------|
| Trigger suggestion | `Ctrl + Space` |
| Rename symbol | `F2` |
| Format document | `Shift + Option + F` |
| Go to definition | `F12` |
| Peek definition | `Alt + F12` |
| Go to references | `Shift + F12` |

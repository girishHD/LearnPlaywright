# VS Code Keyboard Shortcuts for Windows

## General
| Action | Shortcut |
|--------|----------|
| Command Palette | `Ctrl + Shift + P` |
| Quick Open | `Ctrl + P` |
| Settings | `Ctrl + ,` |
| Keyboard Shortcuts | `Ctrl + K Ctrl + S` |

## Editing
| Action | Shortcut |
|--------|----------|
| Cut line | `Ctrl + X` |
| Copy line | `Ctrl + C` |
| Paste | `Ctrl + V` |
| Move line up/down | `Alt + ↑ / ↓` |
| Copy line up/down | `Shift + Alt + ↑ / ↓` |
| Delete line | `Ctrl + Shift + K` |
| Insert line below | `Ctrl + Enter` |
| Insert line above | `Ctrl + Shift + Enter` |
| Indent / Outdent | `Ctrl + ] / [` |
| Go to beginning of line | `Home` |
| Go to end of line | `End` |
| Comment line | `Ctrl + /` |
| Block comment | `Shift + Alt + A` |
| Find | `Ctrl + F` |
| Replace | `Ctrl + H` |
| Find next / previous | `F3 / Shift + F3` |

## Multi-Cursor & Selection
| Action | Shortcut |
|--------|----------|
| Select all occurrences | `Ctrl + Shift + L` |
| Add cursor above/below | `Ctrl + Alt + ↑ / ↓` |
| Undo last cursor | `Ctrl + U` |
| Column selection | `Shift + Alt + drag` |

## Navigation
| Action | Shortcut |
|--------|----------|
| Go to file | `Ctrl + P` |
| Go to symbol | `Ctrl + Shift + O` |
| Go to line | `Ctrl + G` |
| Go back / forward | `Alt + ← / Alt + →` |
| Toggle sidebar | `Ctrl + B` |
| Toggle terminal | `Ctrl + \`` |
| Open file in new tab | `Ctrl + Enter` (from Quick Open) |

## Search & Replace
| Action | Shortcut |
|--------|----------|
| Search in files | `Ctrl + Shift + F` |
| Replace in files | `Ctrl + Shift + H` |
| Toggle search details | `Ctrl + Shift + J` |

## Debug
| Action | Shortcut |
|--------|----------|
| Start / Continue | `F5` |
| Step over | `F10` |
| Step into | `F11` |
| Step out | `Shift + F11` |
| Toggle breakpoint | `F9` |
| Stop | `Shift + F5` |

## Terminal
| Action | Shortcut |
|--------|----------|
| Toggle terminal | `Ctrl + \`` |
| New terminal | `Ctrl + Shift + \`` |
| Clear terminal | `Ctrl + K` |

## Split Editor
| Action | Shortcut |
|--------|----------|
| Split editor | `Ctrl + \` |
| Switch between editors | `Ctrl + 1 / 2 / 3` |
| Close editor | `Ctrl + W` |
| Close all editors | `Ctrl + K W` |

## Code Editing
| Action | Shortcut |
|--------|----------|
| Trigger suggestion | `Ctrl + Space` |
| Rename symbol | `F2` |
| Format document | `Shift + Alt + F` |
| Go to definition | `F12` |
| Peek definition | `Alt + F12` |
| Go to references | `Shift + F12` |

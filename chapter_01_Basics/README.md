# Chapter 01 - Basics (Getting Started with Programming)

---

## What This Chapter Is

This chapter introduces fundamental programming concepts: outputting text, storing data in variables, repeating operations with loops, and creating reusable functions. It also verifies your development environment is set up correctly.

---

## Files in This Chapter

### 01_Basics.js
Prints "Hello World!" to the console and declares a variable `x` with the value 10. The simplest introduction to JavaScript output and variable storage.

### 02_JS.js
Demonstrates `for` loops — repeating an operation multiple times. Counts from 0 to 999 and defines a reusable `print()` function to avoid code duplication.

### 03_Verify_Setup.js
System verification script that checks the operating system (Windows/Mac/Linux), processor architecture (32/64-bit), and Node.js version to ensure everything is configured correctly.

### 04_HotCode.js
Defines an `add(a, b)` function and executes it 10,000 times to demonstrate the computer's speed at repetitive calculations.

---

## Why This Matters

Without understanding the basics, you're just running code without comprehension. This chapter establishes the foundation: console output, variables, loops, and functions are the building blocks of every program you'll write.

---

## What You'll Learn

- Console output with `console.log`
- Storing data in variables
- Repeating operations with loops
- Creating and calling functions
- Verifying your development environment

---

## Key Terms

| Term | Definition |
|---|---|
| Variable | A named container that holds a value |
| Function | A reusable block of code that performs a task |
| Loop | A construct that repeats a block of code |
| Console | The environment where program output is displayed |
| Argument | A value passed to a function for processing |

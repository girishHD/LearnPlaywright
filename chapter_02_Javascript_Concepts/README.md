## What This Chapter Is

This chapter covers `var` — the original JavaScript keyword for declaring variables. While modern JavaScript prefers `let` and `const`, understanding `var` is important for reading legacy code.

---

## Files in This Chapter

### 05_JS_Basics.js
Declares a variable `v` with the value 10 using `var`, then reassigns it to 12. Demonstrates that `var` variables can be freely reassigned at any time.

Steps:
1. Declare variable `v` with value 10
2. Read the value (10)
3. Reassign to 12
4. Read the new value (12)

---

## Why This Matters

Computers excel at remembering information. Variables are the mechanism that allows programs to store, retrieve, and update data during execution.

---

## What You'll Learn

- `var` is used to declare a variable
- Variables can hold values like numbers
- Variable values can be changed (reassigned)
- The computer reliably remembers stored values

---

## Key Terms

| Term | Definition |
|---|---|
| Variable | A named container for a value |
| Reassign | Replace the current value with a new one |
| Log | Output a value to the console for inspection |

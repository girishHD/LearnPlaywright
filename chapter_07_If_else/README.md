## What This Chapter Is

Decision-making is fundamental to programming. The `if` and `else` keywords allow code to execute different paths based on conditions. This chapter covers conditional logic with real-world QA/testing scenarios.

## Why This Matters

Every decision in a program is an if-else. QA/testing is fundamentally about checking conditions — "If this happens, then verify that result."

---

## What You'll Learn

- `if (condition)` — ask a yes/no question
- `else` — handle the false case
- `else if` — check additional conditions
- Combining multiple conditions
- Real QA scenarios: grading, bugs, status codes, login lockout

---

## Key Terms

| Term | Definition |
|---|---|
| Condition | An expression that evaluates to true or false |
| If | Execute code when condition is true |
| Else | Execute code when condition is false |
| Else If | Check an alternative condition |
| HTTP Status | Server response code indicating request outcome |
| Bug Severity | Classification of how severe a defect is |
